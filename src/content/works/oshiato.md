## なぜ作ったか

エンジニアがこれまで積み重ねてきた開発活動や学習活動は、GitHub や Zenn などに散らばっています。OSHIATO は、それを外部サービスから集めて整理・分析し、エンジニアプロフィール、履歴書、職務経歴書、ポートフォリオなどを生成・可視化するサービスです。

ユーザーが自分で実績を大量に入力するのではなく、すでにある活動データを活用します。単なる「AI で履歴書を作るサービス」ではなく、**エンジニアが実際に積み重ねてきた足跡をデータとして捉え、その足跡から現在の自分と未来のキャリアを作る**ことを目指しています。サービス名の「OSHIATO（足跡）」も、この思想から来ています。

## 構成と技術の選定

```text
外部サービス（GitHub、Zenn、Qiita など）
    ↓
活動データ収集
    ↓
Go バックエンドで正規化・構造化
    ↓
Skill / Project / Activity / Experience などに整理
    ↓
AI による分析・文章生成
    ↓
プロフィール / 履歴書 / 職務経歴書 / ポートフォリオ
```

一番大事にしているのは、**AI に事実を作らせないこと**です。AI は存在しない実績を生成するのではなく、OSHIATO が収集した事実をもとに文章化・分析します。

バックエンドは Go を中心にしています。Go を使うこと自体が目的ではなく、外部 API 連携、OAuth、認証・認可、API の rate limit への対応、並行処理、バックグラウンドジョブ、キャッシュ、retry / timeout、DB 設計、AI API 連携といったバックエンドの技術を実践することが目的です。

## 今後やりたいこと

まずは MVP として、次の範囲に絞って作ります。

- GitHub などの外部サービスと連携して、活動データを取得する
- Go バックエンドでデータを正規化し、技術・プロジェクト・活動などに整理する
- AI でエンジニアプロフィールや、履歴書・職務経歴書を生成する
- Web 上でプロフィールとして表示する

その後は、Zenn / Qiita などとの連携を増やし、最終的には **活動記録 → スキル分析 → プロフィール → 応募書類 → 求人・インターン → キャリア形成** までつなげたいと考えています。

- 求人・インターンとのマッチング：適合度、自分の強み、不足しているスキルの提示
- 求人ごとの応募支援：アピールすべきプロジェクト、自己 PR、面接で聞かれそうな内容の生成
- キャリア形成：「次に何を作るべきか」「どんな技術を学ぶと選択肢が広がるか」の提案
